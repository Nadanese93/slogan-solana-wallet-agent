A one-line slogan generator for a Solana wallet agent.

Running `main.py` writes exactly one slogan — one line, at most 140
characters and at most 20 words — to `entry.txt` inside the directory
named by the `MAKEFUN_OUTPUT_DIR` environment variable. The output is
deterministic: the same bytes on every run.

## Usage

Set `MAKEFUN_OUTPUT_DIR` to an output directory, then run:

    python3 main.py

The program exits with code 2 and a clear error message when
`MAKEFUN_OUTPUT_DIR` is not set.
